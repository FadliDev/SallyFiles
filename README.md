# Sally Files

File manager Android ringan ala ZArchiver. Kotlin + Jetpack Compose + Material 3 (aksen biru, dark mode penuh).

- Browse, copy/cut/paste, hapus, rename, folder/file baru, bagikan
- Kompres ZIP; ekstrak ZIP/TAR/TAR.GZ/GZ/7Z/APK/JAR
- Dark mode: ikuti sistem / terang / gelap, opsi AMOLED, opsi warna dinamis
- Pengaturan: tema, sort, file tersembunyi, konfirmasi hapus, kelola lokasi
- Lokasi kustom: folder SAF (Termux, Acode, SD card, provider lain) atau path manual

## Build
Push ke GitHub (branch main) -> tab Actions -> artifact `SallyFiles-apk`.
