# Sally Files

File manager Android ringan ala ZArchiver. Kotlin + Material 3, tanpa Compose.

Fitur: browse, copy/cut/paste, hapus, rename, folder/file baru, kompres ZIP, ekstrak ZIP/TAR/TAR.GZ/GZ/7Z/APK/JAR, sort, file tersembunyi, buka file via aplikasi lain.

## Build
Push ke GitHub (branch main) -> tab Actions -> artifact `SallyFiles-apk`.
